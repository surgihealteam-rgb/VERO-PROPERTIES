# VERO PROPERTIES

Hyderabad-focused property lead-generation website.

## Deploy
1. Create a free Vercel account.
2. Create a GitHub repository and upload these files, or deploy the folder with Vercel.
3. Import the project into Vercel.
4. After deployment, add `veroproperties.co` under Vercel Project Settings → Domains.
5. Add the DNS records Vercel provides at your domain registrar.
6. Replace the placeholder WhatsApp number in `app/page.js` if required.

## Lead handling
The first version opens a pre-filled WhatsApp enquiry. No paid CRM/database is required.
